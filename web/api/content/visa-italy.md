# Подача в Италию

Первая точка маршрута — Рим, поэтому консульство Италии логично как основное.

## Где подаём

- Казахстан: визовый центр Италии (VFS Global / актуальный подрядчик на дату подачи).
- Города подачи обычно: Астана и Алматы. Слоты заканчиваются быстро — бронируем, как только пакет готов.

## Как проходит визит

1. Онлайн-запись на конкретного человека.
2. Распечатанная анкета, оригиналы и копии.
3. Биометрия (отпечатки + фото).
4. Оплата сервисного сбора визового центра + консульский сбор.
5. Трекинг заявления.

## На собеседовании / окошке

Говорите просто и правду:

- едете **групповым авторским туром**;
- маршрут: Рим → Венеция → Париж → Цюрих → Лаутербруннен;
- обратно в Алматы **из Цюриха через Стамбул**;
- работа / учёба ждёт на месте, билет обратно куплен.

Не выдумывайте «бизнес-поездку», если это туризм. Не спорьте с офицером.

## Частые отказы

- слабая выписка или «мёртвый» счёт;
- бронь отеля не стыкуется с билетами;
- паспорт почти истекает;
- раньше были нарушения шенгена.

Если уже был отказ — принесите старое решение, разберём cover letter.
