# После одобрения

Виза есть — теперь собираем вылет без сюрпризов.

## Сразу после паспорта

1. Проверьте даты визы: въезд не раньше, выезд не позже.
2. Пришлите фото разворота с визой координатору.
3. Выкупаем / подтверждаем авиа: **Алматы → Стамбул → Рим**, обратно **Цюрих → Стамбул → Алматы**.
4. Поезда: Рим → Венеция, Париж → Цюрих, Цюрих → Лаутербруннен. Билеты и места скинем в общий чат.
5. Страховка должна покрывать **все дни**, включая перелёт домой.

## Чаты и связь

- общий чат группы (WhatsApp / Telegram);
- личный контакт координатора на случай аэропорта;
- офлайн-карта: Organic Maps / Google Maps скачать Рим, Венецию, Париж, Цюрих, Лаутербруннен.

## Деньги в поездке

- карта Visa/Mastercard с уведомлениями;
- немного наличных евро на первый день;
- Apple Pay / Google Pay работают почти везде.

## Если визу задержали

Не молчите. Пишем в визовый центр, параллельно держим гибкие билеты. План B по датам обсуждаем только в чате группы, не в сторис.
