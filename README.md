# ARALA Tours (`@arala.tours`)

Авторский Классический Евротур из Казахстана: Алматы → Милан → Венеция → Рим (Ватикан) → Париж → Базель → Цюрих → Лаутербруннен → Мюррен → Алматы.

Стек: **Angular 22** + **Leaflet** (живая F1-телеметрия маршрута) + **Vercel Serverless / Go API**. Закрытый визовый гайд открывается после оплаты тура — аккаунты создаются в `/admin`.

## Запуск

Нужен Node **22.22.3+** (или **24+**) и Go **1.26**.

Терминал 1 — API:

```bash
cd server
go run ./cmd/api
```

Терминал 2 — сайт:

```bash
cd web
npm start
```

Откройте http://localhost:4200
