# ARALA Tours (`@arala.tours`)

Авторский Классический Евротур из Казахстана: Алматы → Милан → Венеция → Рим (Ватикан) → Париж → Базель → Цюрих → Лаутербруннен → Мюррен → Алматы.

Сайт: **https://arala-tours.vercel.app**

Стек: **Angular 22** + предзагруженная векторная Canvas-карта с 60fps F1-телеметрией маршрута + двуязычный интерфейс (**ҚАЗ** основной / **РУС** переключатель) + мгновенное бронирование в WhatsApp.

## Локальный запуск

Нужен Node **22.22.3+** (или **24.15+**):

```bash
cd web
npm install
npm start
```

Откройте http://localhost:4200
