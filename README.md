# iTour

Авторский евротур: Алматы → Рим (Ватикан) → Венеция → Париж → Цюрих → Лаутербруннен → Алматы. Пересадка в Стамбуле.

Стек: **Angular 22** + **Go**. Главная в духе Apple, маршрут анимируется при скролле. Гайды по визе открываются только после покупки — аккаунты создаются в админке.

## Запуск

Нужен Node **24.15+** (или 22.22.3+) и Go 1.26.

Терминал 1 — API:

```bash
cd server
go run ./cmd/api
```

Терминал 2 — сайт:

```bash
cd web
npm start
```

Откройте http://localhost:4200

| Роль | Email | Пароль |
|---|---|---|
| Админ | `admin@itour.kz` | `iTourAdmin2026!` |

Заявки с главной падают в админку. Связь на лендинге: Instagram и WhatsApp.
